# AutoBM25：面向任意语料的 BM25 零标注自适应 —— 统计特征 → 参数大字典（O(1) 查表 + OOD 防护 + 启发式回退）

> **核心命题：** BM25 的最优超参数（k1, b, k3, δ, IDF 类型）不是“默认值”，而是语料统计结构的函数。本项目用一个**可增量生长的参数大字典**来学习这个函数：输入任意数据集的 18 维统计特征 → O(1) 最近邻查表得到超参数；分布外（OOD）或未命中时，回退到可解释的启发式规则。在 16 个 BEIR 数据集（3.6k–884 万文档）上，13/16 优于固定默认参数（平均 NDCG@10 +11.6%）；**通过“多语料拼接”将词典扩充到 30 个条目（1.67×），命中率提升至 88.9%，词典优先路径使全部 16 个数据集不劣于默认参数。**

---

## TL;DR（核心贡献）

1. **18 维统计特征体系（P0/P1/P2）**：文档长度分布、词频冗余度、词汇增长、查询侧特征——每个特征都带明确的"机制假设"（为什么它能预测某个参数）。
2. **参数大字典（非参数记忆）**：`特征向量 → 最优参数` 的最近邻查找，含**分布外（OOD）防护**与**启发式回退**；每新增一个做过 grid search 的数据集，字典就多一条经验，普适性随覆盖度单调增长。
3. **k3（查询词频饱和项）经消融试验确认有效**：5/6 数据集正增益，长查询场景（fiqa +19.9%、arguana +7.5%）收益显著，已纳入参数空间。
4. **数据拼接（Mixing）是有效的词典增强策略**：把已有语料多次组合拼接生成“跨域混合样本”，词典从 12 → 18 → 30 条目，命中率 70.6% → 84.0% → **88.9%**，且让原本 OOD 的语料（webis、msmarco、hotpotqa 等）重新命中。
5. **规模验证到 884 万文档**：msmarco/fever/hotpotqa/climate-fever/dbpedia-entity 等超大规模语料（分层子采样，相关标注全保留）。

## 1. 研究背景与动机

### 1.1 BM25 的"默认值假设"与它的代价

BM25 打分：

```
score(D, Q) = Σ_{q∈Q} IDF(q) · [ f(q,D)·(k1+1) / (f(q,D) + k1·(1 − b + b·|D|/avgdl)) ]
                        · [ f(q,Q)·(k3+1) / (f(q,Q) + k3) ]
```

k1 控制文档词频饱和，k3 控制查询词频饱和（查询内重复词越多越重要），b 控制长度归一化强度，IDF 决定稀有词权重。BM25+ [3] 增加常数补偿项 δ 缓解短文档过度惩罚。

工程界几乎总是用 k1=1.2, b=0.75（源自早期 TREC 调参 [1][2]），但不同语料的最优参数差异极大：短而精炼的语料偏好小 k1，重复度高的长文本偏好大 k1；单域语料内长度差异越大 b 应越小。**固定默认值 = 假设所有语料统计结构相同**——跨域应用时该假设系统性失效（§5.2 中 4/17 数据集验证了默认值不是最优）。

### 1.2 零标注自适应的核心洞察

调参需要标注，但"最优参数"由语料的统计结构决定，而统计结构**不需要标注即可测量**：

- 文档长度分布（cv_len, skew, p90/p10）→ b；
- 文档内词频冗余（TTR, max_tf, length_tf_corr）→ k1；
- 查询内重复度（avg_query_max_tf, query_repeat_ratio）→ k3；
- 词汇增长与稀疏性（heaps_beta, hapax_ratio, zipf_alpha）→ IDF 变体。

更进一步：**统计特征 → 最优参数 的映射本身可以从已有数据集上学出来**。这就是"参数大字典"——一个可解释、可增量扩展的非参数记忆，取代"每个新数据集重新调参"的昂贵流程。

## 2. 问题定义与系统架构

### 2.1 形式化

给定文档集 D 与查询集 Q，特征提取器 Φ(D,Q) → **f** ∈ ℝ¹⁸，参数预测 g(**f**) → θ = (k1, b, k3, δ, idf_type)。目标：

```
θ* = argmax_{θ∈Θ} NDCG@10(D, Q, qrels; θ)          # grid search 上界（需要标注）
minimize  NDCG@10(θ*) − NDCG@10(g(Φ(D,Q)))          # 零标注预测与上界的差距
```

### 2.2 系统架构（推理路径）

```
               ┌─────────────────────────────────────────────┐
  新数据集 ──► │ Φ(D,Q)  18 维统计特征                        │
               │    │                                         │
               │    ▼                                         │
               │ 参数大字典（O(1) 最近邻，归一化特征空间）     │
               │    │                                         │
               │    ├─ 命中（距离 ≤ τ 且非 OOD）──► θ_dict     │
               │    └─ 未命中 / 分布外 ──► 启发式规则 ──► θ_heur │
               │                     │                        │
               │                     ▼                        │
               │           θ = θ_dict 或 θ_heur               │
               │                     │                        │
               └─────────────────────┼────────────────────────┘
                                     ▼
                          BM25/BM25+ 检索引擎（k1/b/k3/δ/IDF）
```

**为什么不用神经网络：** 目标是"小幅、可解释、零成本"的调整；最近邻查表在语义上等价于对"参数景观"做局部线性近似，且每次新增标定数据集都能即时扩充分布覆盖，无需重训。

## 3. 方法

### 3.1 统计特征体系（feature_extractor.py）

分词：空格 + 小写，不去停用词（停用词只用于密度统计）。P0=必须，P1=建议，P2=可选。

**维度一 · 文档长度与分布（→ b）**

| 特征                      | 优先级 | 定义              | 机制假设                                       |
| ------------------------- | ------ | ----------------- | ---------------------------------------------- |
| doc_count                 | P0     | 文档总数          | 样本量 / OOD 检测                              |
| avgdl / std_len           | P0     | 平均长度 / 标准差 | 归一化参照与离散度                             |
| cv_len                    | P0     | std_len / avgdl   | **单域内 cv_len↑ → b↓**（保护短文档） |
| len_skew                  | P1     | 长度偏度          | 超长文档长尾                                   |
| len_p90 / len_p10 / ratio | P1     | 分位数            | 稳健长尾度量                                   |

**维度二 · 文档内词频与冗余（→ k1）**

| 特征           | 优先级 | 定义                       | 机制假设                              |
| -------------- | ------ | -------------------------- | ------------------------------------- |
| avg_ttr        | P0     | 平均类型-标记比            | **TTR↑ → k1↓**               |
| avg_max_tf     | P0     | 去停用词最大词频均值       | 词频饱和天花板                        |
| length_tf_corr | P0     | 长度与平均词频的皮尔逊相关 | **corr↑ → b↑**（长文档冗余） |
| hapax_ratio    | P1     | 单次词占比                 | 词汇稀疏性                            |

**维度三 · 全局词汇分布（→ IDF）**

| 特征             | 优先级 | 定义            | 机制假设                  |
| ---------------- | ------ | --------------- | ------------------------- |
| vocab_size       | P1     | 词汇表大小      | 规模 / OOD 检测           |
| heaps_beta       | P1     | Heaps' Law 指数 | 词汇增长速率              |
| stopword_density | P1     | 停用词占比      | 语言相关（非英文语料≈0） |
| zipf_alpha       | P2     | Zipf 指数       | 词频分布陡峭度            |

**维度四 · 查询侧特征（P2，→ k3 与查询自适应）**

| 特征               | 定义               | 机制假设                   |
| ------------------ | ------------------ | -------------------------- |
| avg_query_len      | 平均查询长度       | 长查询 → 查询词频饱和重要 |
| avg_query_max_tf   | 查询内最大词频均值 | **重复词↑ → k3↑** |
| query_repeat_ratio | 重复查询占比       | 同上                       |
| query_idf_mean/std | 查询词 IDF 统计    | 查询特异性                 |
| query_oov_ratio    | OOV 查询词占比     | 词汇匹配风险               |

### 3.2 启发式规则（rule_predictor.py，系数在 config.yaml）

```
k1    = clip(k1_base − α_ttr·avg_ttr + α_maxtf·min(avg_max_tf/20,1), 0.5, 3.0)
b     = clip(b_base + β_corr·length_tf_corr − β_cv·cv_len, 0, 1)
k3    = clip(κ_base·(avg_query_max_tf−1) + κ_rep·query_repeat_ratio, 0, 8)
δ     = clip(γ·cv_len, 0, 2.0)
idf   = smoothed（若 heaps_beta>0.7 或 hapax_ratio>0.6），否则 rsj
```

符号方向由机制假设决定；系数由非负最小二乘（NNLS）标定。

### 3.3 参数大字典（param_dictionary.py）

- **构建**：每个做过 grid search 的数据集保存（特征, 最优参数, 上界指标），并记录特征归一化统计量（mean/std/min/max）→ **`dictionary/param_dictionary.json`**（独立目录、随仓库提交，`python main.py --build-dict` 可重建）；
- **查表（O(1)）**：归一化欧氏距离最近邻，距离 ≤ `match_threshold`（默认 2.0）命中；k 近邻可做连续参数平均 + IDF 多数票；
- **OOD 防护**：≥ `oov_min_features`（默认 2）个特征超出训练覆盖范围 → 拒绝命中、回退启发式。防止把极端语料的最优参数（如 webis 的 b=0.0）硬套到结构不同的新语料（如混合语料）上；
- **诊断接口 `probe()`**：返回 OOD 状态、最近距离、最近条目，用于可解释的命中率审计。

### 3.4 数据拼接（Mixing）：词典的跨域增强（mix_corpora.py）

动机：真实"新数据集"可能恰好落在已有条目的覆盖盲区（如超长查询、跨域混合）。把已有语料按不同配方**拼接**（doc_id 加前缀防冲突、分层采样保相关标注），对每个拼接体做 grid search 得到其最优参数，作为新条目——等于主动在特征空间中"补点"。

8 个固定配方（见 §5.5），覆盖 2–4 语料组合、不同查询类型。该方法成本低（子采样规模），收益已验证（§5.4–5.5）。

### 3.5 数据增强与系数标定（data_augmentation.py / evaluator.py）

随机子采样、长度分桶、截断、滑动窗口等变换扩充（特征, 最优参数）样本；grid search 造 ground truth → NNLS 拟合系数 → 更新 config → 留出集报告。

- 引擎：自实现倒排索引 BM25/BM25+（numpy 向量化，查询词按唯一词 + k3 饱和因子计分）；
- 复现：`python run_experiments.py --all --eval-queries -1`，结果存 `results/benchmark_results.json`，表格由 `python summarize_results.py` 生成。

| **扩充（+6 拼接条目）** |     18 | **84.0%** (21/25) | **LOO 83.3%** (15/18) | **85.7%** (6/7) | **100%** (8/8) |
| **再扩充（+12 新拼接条目）** | 30 | **88.9%** (32/36) | **LOO 90.0%** (27/30) | **83.3%** (5/6) | **100%** (18/18) |

命中/回退有清晰分界：命中簇最近邻距离一般 ≤1.3，回退簇距离 ≥2.2 或 OOD。

**LOO 检索质量（`python evaluate_dictionary.py`，NDCG@10）**

| 指标                | 9 条目词典 | 18 条目词典 | **30 条目词典** |
| ------------------- | ---------: | ----------: | --------------: |
| 命中率              |        6/9 |     15/18 |       **27/30** |
| dict+回退 平均 NDCG |     0.3503 |     0.3998 |      **0.4285** |
| 纯启发式 平均 NDCG  |     0.3005 |     0.3566 |          0.3894 |
| grid 上界 平均 NDCG |     0.3768 |     0.4486 |          0.4753 |
| dict+回退 达上界    |      93.0% |     89.1% |       **90.1%** |

关键案例：**webis-touche2020** 在 9 条目词典下 OOD 回退（0.2895），加入拼接条目后命中词典（**0.3087**，+6.6%）；**msmarco/hotpotqa** 命中新拼接条目（mix17/mix05）后显著优于启发式；**fever** 命中后 0.6736 vs 启发式 0.5352（+25.9%）；**mix14（dbpedia+webis）** 命中后 0.3931 vs 启发式 0.2795（+40.6%）。

**结论 3：词典需要改进，而改进有效。** 单靠真实语料条目，新数据集命中 80%；拼接条目使总命中率 70.6% → 88.9%、混合语料全覆盖；剩余未命中（arguana、vihealthqa、climate-fever、nq）均为极端/OOD 样本——恰是“多拼接、多标定”应继续补点的区域。

### 5.4 拼接（Mixing）作为词典增强：配方与效果

| 拼接体 | 组成                       |  文档数 | grid 最优 (k1, b, k3, δ, IDF) | NDCG@10 |
| ------ | -------------------------- | ------: | ------------------------------ | ------: |
| mix00  | fiqa+nfcorpus+scifact      |  66,454 | (2.0, 0.0, 0, 0, smoothed)     |  0.077* |
| mix01  | trec-covid+scidocs+scifact |  90,840 | (3.0, 0.4, 1.2, 0.5, smoothed) |   0.594 |
| mix02  | webis+arguana              |  68,674 | (3.0, 0.2, 1.2, 0, smoothed)   |   0.595 |
mix03  | nq+msmarco
| mix04  | fever+climate-fever        | 119,998 | (2.5, 0.0, 0, 0.7, smoothed)   |   0.895 |
| mix05  | dbpedia+hotpotqa           | 120,000 | (2.5, 0.9, 1.2, 1.5, smoothed) |   0.375 |

\* mix00 标注稀疏（每查询相关文档少），绝对分低但作为词典条目有效。

**结论 4：拼接是低成本、高收益的词典增强策略。** 20 个拼接体（约 70–180k 文档、40–180 查询）的 grid 成本远低于真实语料

### 5.5 混合语料（Mega）泛化测试：OOD 防护的必要性

10 个语料拼接成 132 万文档混合语料（cv_len=1.73，超出所有训练语料）：

| 配置                                     |          NDCG@10 |           MRR@10 |       Recall@100 |
| ---------------------------------------- | ---------------: | ---------------: | ---------------: |
| default（b=0.75）                        | **0.1247** | **0.0613** | **0.7335** |
| 词典无 OOD 防护（误命中 webis → b=0.0） |           0.0012 |           0.0004 |           0.0160 |
| 词典含 OOD 防护（回退启发式）            |           0.0106 |           0.0054 |           0.1122 |

**结论 5（普适性边界）：** OOD 防护正确避免了灾难性硬命中；但混合语料上默认参数仍优于自适应规则——"cv_len↑→b↓"是**域内**规律，混合语料的长度异质性主要来自域间。真正的普适需要"域内/域间方差分解"或按子语料分别预测（§6）。

## 6. 核心结论

1. **零标注自适应可行**：13/16 数据集优于默认参数，平均 NDCG@10 +11.6%；规模从 3.6k 到 884 万文档均适用；词典优先路径 16/16 不劣于默认。
2. **大字典 + OOD 防护 + 启发式回退是一个有效的普适机制**：LOO 命中 15/18，dict+回退达 grid 上界的 89%。
3. **k3 值得保留**：查询词频饱和项在长查询场景带来近 20% 相对提升。
4. **多拼接显著提升词典覆盖**：词典 12 → 30 条目，命中率 70.6% → 88.9%，混合语料覆盖 0 → 100%。
5. **规律是域条件性的**：混合/极端语料上启发式方向可能失效，OOD 检测与按子语料预测是必要防线。

## 7. 局限性与未来工作

- **长查询族（arguana/climate-fever）持续未命中**：需要长查询专用特征（查询结构、词频分布）或长查询分册；
- **非英文语料**（vihealthqa）：语言无关特征或按语言分册；
- **域内/域间长度异质性分解**：让"cv_len→b"规律在混合语料上成立；
- **OOD 阈值与距离度量的自动化**：当前 (τ=2.0, margin=0.5, min_features=2) 为经验设定，可用验证集搜索；
- **超大规模语料的子采样口径**：200–300k 子采样的特征/上界与全量存在偏差，后续可用全量特征（流式计算）修正；
- **词典索引规模化**：条目超过千级后引入 KD-tree/Ball-tree 保持 O(log n)；
- **端到端标定**：当前结论基于固定启发式系数，`--calibrate` 与增强数据可进一步收紧。

## 8. 快速开始（复现）

```bash
pip install -r requirements.txt

# 单数据集预测（词典优先 + 回退）与评估
python main.py --dataset dataset/XXX --predict
python main.py --dataset dataset/XXX --eval --no-dict        # 只用启发式
python main.py --dataset dataset/XXX --eval --grid --limit-queries 100 \
    --grid-k3 0 1.2 4                                        # grid 上界（可缩 k3 轴加速）

# 批量实验 + 结果汇总（README 表格入口）
python run_experiments.py --all --eval-queries -1 --max-docs 200000
python summarize_results.py

# 参数大字典：构建 / 命中率分析 / 留一法质量评估
python main.py --build-dict
python analyze_dictionary.py --mixes-benchmark results/benchmark_mixes.json
python evaluate_dictionary.py --thresholds 2.0

# 拼接增强：构建 8 个混合语料 → 对每个做 grid → 并入词典
python mix_corpora.py
python run_experiments.py --datasets results/mixed_corpora/mix00 ... \
    --grid-datasets results/mixed_corpora/mix00 ... --grid-queries 40 --grid-k3 0 1.2

# 专项：k3 消融 / 混合语料泛化
python experiment_k3.py
python mega_corpus.py --eval-queries 500 --skip-build
```

数据格式支持标准格式（docs/queries/qrels.jsonl）与 BEIR 格式（corpus.jsonl / qrels/*.tsv，自动识别 `_id`/`qid` 与 `query-id/corpus-id` 表头）。**`dictionary/param_dictionary.json` 随仓库提交**（大字典开箱即用）；**三个实验基准数据**（`results/benchmark_results.json`、`results/benchmark_mixes.json`、`results/benchmark_grid_sample_eval.json`）也随仓库提交，因此 `--build-dict` 与命中率分析在克隆后可直接复现；其余中间产物（LOO 报告、命中率报告、大 grid 结果等）存 `results/`（gitignored，可用脚本重建）。
