# AutoBM25：基于语料统计特征的 BM25 超参数自适应选择

> **零标注、零调参：只通过分析文档集自身的统计特征，预测最优 BM25 超参数（k1, b, k3, δ, IDF 类型）。核心交付是一个"大字典"——输入任意数据集的统计特征，O(1) 查表得到超参数；查不到（分布外）时回退到启发式规则。在 12 个 BEIR 数据集上，9/12 优于固定默认参数（平均 NDCG@10 +14.6%），同口径下达到 grid search 上界的 68%–102%。**

## 摘要

BM25 是信息检索中最经典、应用最广的词袋排序模型，但其检索性能对超参数高度敏感：不同数据集的参数最优值差异极大，而实际工程中几乎总是使用固定默认值（k1=1.2, b=0.75），原因是最优参数需要带标注的验证集做网格搜索，新数据集往往没有标注。

本项目研究一个更根本的问题：**能否在不使用任何相关性标注的前提下，仅通过分析语料本身的统计特征，直接预测该数据集最合适的 BM25 超参数？** 我们设计了 18 维统计特征体系（P0/P1/P2 分层），构建了**参数词典（大字典）**：用 grid search 在已有数据集上造出（特征向量 → 最优参数）条目，预测时对任意新数据集做 O(1) 最近邻查表；当特征超出词典覆盖范围（分布外，OOD）或找不到近邻时，回退到启发式公式。

在 12 个覆盖金融、医学、科学文献、开放域问答、社区问答、论点检索等领域的 BEIR 数据集（3.6k–268 万文档）上：

- 零标注规则/词典预测在 **9/12** 数据集上优于固定默认参数，平均 MRR@10 +10.3%、NDCG@10 +14.6%、Recall@100 +6.5%；
- 在同口径查询子集上，预测达到 grid search 上界的 **68%–102%**（平均约 82%）；
- 查询词频饱和项 **k3 经消融试验确认有效**（5/6 数据集有正增益，长查询场景尤甚），已纳入参数空间；
- 参数词典留一法（LOO）评估：6/9 命中，**dict+回退比纯启发式平均高 16.6%**（NDCG@10 0.350 vs 0.300），达到 grid 上界的 93%；
- 跨域混合语料测试（10 个语料拼接，132 万文档）验证了 OOD 防护的正确性：混合语料被判定分布外并回退，但同时也暴露出"cv_len 高 → b 小"这一启发式在混合语料上方向失效——这是重要的普适性边界，详见 §5.5 与 §6。

## 1. 研究背景与动机

### 1.1 BM25 与默认参数的"普适性假设"

BM25 对查询 q 在文档 D 上的打分形式为：

```
score(D, Q) = Σ_{q∈Q} IDF(q) · [f(q,D)·(k1+1) / (f(q,D) + k1·(1 − b + b·|D|/avgdl))]
                        · [f(q,Q)·(k3+1) / (f(q,Q) + k3)]
```

其中 `f(q,D)` 是查询词在文档中的词频，`f(q,Q)` 是查询词在查询中的词频，`avgdl` 是语料平均文档长度。k1 控制文档词频的饱和速度；**k3 控制查询词频的饱和速度**（查询内重复词越多，k3 的影响越大；k3=0 时重复查询词只计一次）；b 控制文档长度归一化强度；IDF 决定稀有词的权重。BM25+ [3] 额外为每个匹配词增加常数补偿项 δ，缓解短文档被长度归一化过度惩罚的问题。

经验上 k1=1.2、b=0.75 来自早期 TREC 语料 [1][2]，但不同领域、不同文本类型的最优参数差异显著：短而精炼的语料偏好小 k1，重复度高的长文本偏好大 k1；文档长度差异极大的语料应降低 b，否则短文档被系统性过度惩罚。固定默认参数等于假设所有语料具有相同的统计结构——这一假设在跨领域应用中并不成立。

### 1.2 零标注自适应：为什么统计特征可以预测最优参数

调参的障碍在于需要标注。但如果"最优参数"本质上由语料的**统计结构**决定，那么可以直接测量这种结构：

- **文档长度分布**决定 b：长度差异越大（cv_len 高），长度归一化越容易把短文档打到接近零分，因此最优 b 应越小（在**单一领域语料内**成立）；文档长度与词频的共变关系（length_tf_corr）区分"长文档只是更长"与"长文档携带独特内容"。
- **文档内词频冗余度**决定 k1：TTR 接近 1 说明词频信号很快饱和，k1 应小；TTR 低说明词频冗余多，需要更大的 k1 让高频词持续贡献。
- **查询内重复度**决定 k3：查询越长、重复词越多（avg_query_max_tf、query_repeat_ratio 高），查询词频饱和项越重要，k3 应越大。
- **词汇增长与稀疏性**决定 IDF 变体：Heaps' Law 指数 β [5] 与 hapax ratio 刻画词汇稀疏性；多领域、词汇稀疏的语料中稀有词携带更强判别信号，平滑 IDF 更合适。

## 2. 问题定义

给定文档集 D 与查询集 Q，定义统计特征提取器 Φ(D, Q) → **f** ∈ ℝ^18，以及参数预测函数 g(**f**) → **θ** = (k1, b, k3, δ, idf_type)。目标是在**不使用相关性标注**的条件下，使零标注预测参数的检索性能逼近 grid search 上界：

```
θ* = argmax_{θ ∈ Θ} NDCG@10(D, Q, qrels; θ)
minimize  NDCG@10(θ*) − NDCG@10(g(Φ(D, Q)))
```

搜索空间：k1 ∈ {0.5, 0.8, 1.0, 1.2, 1.5, 2.0, 2.5, 3.0}，b ∈ {0.0, 0.2, ..., 1.0}，k3 ∈ {0.0, 1.2, 4.0}（消融试验另扫 0–8），δ ∈ {0.0, 0.3, ..., 1.5}，idf_type ∈ {rsj, smoothed}。

**总体设计（普适规律 + 冷启动兜底）**：

```
新数据集 → 统计特征 Φ(D,Q) ─┬─ 参数词典查表（O(1) 最近邻，含 OOD 防护）→ θ_dict
                             └─ 未命中/分布外 → 启发式规则（系数可标定）→ θ_heur
最终参数 = θ_dict（若命中），否则 θ_heur
```

词典不是神经网络的替代品，而是一个**可解释、可增量扩展**的非参数记忆：每新增一个做过 grid search 的数据集，词典就多一条经验，普适性随覆盖度增长。

## 3. 方法

### 3.1 统计特征体系（feature_extractor.py）

特征按实现优先级分为 P0（必须）、P1（建议）、P2（可选），按预测目标分为四个维度。分词方式统一为空格分词 + 小写化，不去停用词（停用词仅用于单独的密度统计）。

**维度一：文档长度与分布特征（决定 b）**

| 特征 | 优先级 | 定义 | 机制假设 |
|---|---|---|---|
| doc_count | P0 | 文档总数 | 样本量 / 分布外检测 |
| avgdl | P0 | 平均文档长度（词数） | 长度归一化的参照量 |
| std_len | P0 | 文档长度标准差 | 长度离散度 |
| cv_len | P0 | 变异系数 = std_len / avgdl | **单域语料内 cv_len 高 → b 应小** |
| len_skew | P1 | 长度分布偏度 | 偏度高 → 少量超长文档 |
| len_p90 / len_p10 | P1 | 长度 90/10 分位数 | 稳健位置量 |
| len_ratio_p90_p10 | P1 | p90 / p10 | 长度长尾程度 |

**维度二：文档内词频与冗余度特征（决定 k1）**

| 特征 | 优先级 | 定义 | 机制假设 |
|---|---|---|---|
| avg_ttr | P0 | 平均类型-标记比 | **TTR 高 → k1 应小**；TTR 低 → k1 应大 |
| avg_max_tf | P0 | 每篇文档去停用词后的最大词频均值 | 词频饱和天花板；值高 → k1 应大 |
| length_tf_corr | P0 | 文档长度与文档内平均词频的皮尔逊相关 | **corr 高 → 长文档冗余多 → b 应大** |
| hapax_ratio | P1 | 只出现一次的词 / 词汇量 | 词汇稀疏性 |

**维度三：全局词汇分布特征（决定 IDF 类型）**

| 特征 | 优先级 | 定义 | 机制假设 |
|---|---|---|---|
| vocab_size | P1 | 词汇表大小 | 语料规模 / 分布外检测 |
| heaps_beta | P1 | Heaps' Law 拟合 β | 词汇增长速率 |
| stopword_density | P1 | 停用词占比 | 非英文语料中该特征接近 0（如 vihealthqa） |
| zipf_alpha | P2 | Zipf 律拟合指数 | 词频分布陡峭程度 |

**维度四：查询侧特征（P2，驱动 k3 与查询自适应）**

| 特征 | 定义 | 机制假设 |
|---|---|---|
| avg_query_len | 平均查询长度 | 长查询 → 查询词频饱和更重要 |
| avg_query_max_tf | 查询内最大词频的均值 | **重复词越多 → k3 应越大** |
| query_repeat_ratio | 存在重复词的查询占比 | 同上 |
| query_idf_mean / query_idf_std | 查询词在语料中 IDF 的均值/标准差 | 查询特异性 |
| query_oov_ratio | 查询中 OOV 词占比 | 词汇匹配风险（nfcorpus 达 10.7%） |

### 3.2 启发式参数预测规则（rule_predictor.py）

系数全部写在 `config.yaml` 中，可由标定流程重拟合：

```
k1    = clip(k1_base − alpha_ttr·avg_ttr + alpha_maxtf·min(avg_max_tf/20, 1), 0.5, 3.0)
b     = clip(b_base + beta_corr·length_tf_corr − beta_cv·cv_len, 0, 1)
k3    = clip(k3_base·(avg_query_max_tf−1) + k3_rep·query_repeat_ratio, 0, 8)
δ     = clip(gamma_delta·cv_len, 0, 2.0)
idf   = smoothed（若 heaps_beta > 0.7 或 hapax_ratio > 0.6），否则 rsj
```

### 3.3 参数词典：大字典（param_dictionary.py）

**构建**：对每个做过 grid search 的数据集，保存（特征向量, 最优参数, 上界指标）条目与特征归一化统计量（mean/std/min/max），输出 `results/param_dictionary.json`。

**查表（O(1)）**：新数据集特征归一化后，计算到各条目的欧氏距离（缺失维度跳过），取最近邻；距离 ≤ `match_threshold`（默认 2.0）视为命中，返回该条目的参数（k 近邻可做连续参数平均 + IDF 多数票）。

**分布外（OOD）防护**：若 ≥ `oov_min_features`（默认 2）个特征超出词典训练覆盖范围（`[min−margin·span, max+margin·span]`，margin 默认 0.5），判定为分布外，**拒绝命中**并回退启发式——避免把一个极端语料的最优参数硬套到结构不同的新语料上。

**回退**：未命中或 OOD 时使用 §3.2 的启发式规则。`main.py` 的预测默认走"词典优先，启发式兜底"（`--no-dict` 可强制只用启发式）。

### 3.4 数据增强（data_augmentation.py）

通过变换文档集扩充（特征向量, 最优参数）样本：随机子采样（0.1/0.3/0.5/0.7 × 3 seeds）、长度分桶 + 首尾桶组合（控制 cv_len 形态）、截断（50/100/200/500 词）、滑动窗口（50/100/200 词窗）。输出到 `dataset/augmented/<name>/`，供标定扩大词典覆盖。

### 3.5 系数标定（evaluator.calibrate）

grid search 造 ground truth → 非负最小二乘（NNLS）按公式结构拟合 k1/b/k3/δ 系数（符号方向由公式保证）→ 网格搜索 IDF 阈值 → 更新 `config.yaml` → 留出数据集输出对比报告。

### 4.2 评估协议

- 分词：空格 + 小写，不去停用词；
- 指标：MRR@10、NDCG@10（支持分级相关性）、Recall@100，top-100；
- 基线：**default**（k1=1.2, b=0.75, k3=0, δ=0, rsj）；**predicted**（词典+回退，未构建词典时为启发式）；**grid_search**（上界）；
- 引擎：自实现倒排索引 BM25/BM25+（numpy 向量化）；查询词按唯一词 + k3 饱和因子计算（重复查询词不重复累加）；
- 复现：`python run_experiments.py --all --eval-queries -1`，结果在 `results/benchmark_results.json`，表格由 `python summarize_results.py` 生成。

### 5.3 k3 消融试验（查询词频饱和项）

在既有 grid 最优参数基础上扫描 k3 ∈ {0, 0.5, 1.2, 2, 4, 8}（同一查询子集）：

| 数据集 | k3=0 | 最优 k3 | 最优 NDCG@10 | Δ |
|---|---:|---:|---:|---:|
| nfcorpus | 0.2836 | 4.0 | 0.2842 | +0.2% |
| scifact | 0.5781 | 8.0 | 0.5883 | +1.8% |
| fiqa | 0.0745 | 2.0 | 0.0893 | +19.9% |
| arguana | 0.3644 | 4.0 | 0.3918 | +7.5% |
| trec-covid | 0.4946 | 1.2 | 0.4986 | +0.8% |
| webis-touche2020 | 0.3587 | 0.0 | 0.3587 | 0% |

联合 grid（k1/b/δ/idf × k3∈{0,1.2,4}）抽查 nfcorpus/scifact，最优组合同样包含 k3=4.0；新增数据集 trec-covid-beir（k3=1.2）与 vihealthqa（k3=4.0）的 grid 最优也选中 k3>0。

**结论 3：k3 保留。** 5/6 数据集有正增益，长查询（arguana、fiqa）收益最明显；webis 无变化。k3 与 k1 存在交互（都对词频饱和建模），当前启发式 k3 与 k1 的组合在 arguana 上过强，是后续标定重点。

### 5.4 参数词典留一法（LOO）评估

对 9 个有 grid 结果的数据集逐一留出，用其余 8 个构建词典，预测（查表或回退）并在同一查询子集评估：

| 数据集 | 模式 | NDCG@10 dict+回退 | 启发式 | grid 上界 |
|---|---|--:|--:|--:|
| nfcorpus | 词典命中 | 0.2787 | 0.2637 | 0.2842 |
| scifact | 词典命中 | 0.5536 | 0.5651 | 0.5870 |
| fiqa | 词典命中 | 0.0821 | 0.0762 | 0.0745 |
| arguana | 回退（OOD） | 0.3106 | 0.3106 | 0.3918 |
| trec-covid | 词典命中 | 0.4986 | 0.3417 | 0.4946 |
| webis-touche2020 | 回退（OOD） | 0.2895 | 0.2895 | 0.3587 |
| trec-covid-v2 | 词典命中 | 0.4788 | 0.3499 | 0.4962 |
| trec-covid-beir | 词典命中 | 0.4946 | 0.3417 | 0.4986 |
| vihealthqa | 回退（OOD） | 0.1664 | 0.1664 | 0.2052 |
| **平均** | 6 命中 / 3 回退 | **0.3503** | 0.3005 | 0.3768 |

**结论 4：词典 + 回退是有效的普适机制。** 6/9 命中（多为"典型"语料簇），平均 NDCG 0.3503，比纯启发式高 **16.6%**，达到 grid 上界的 **93%**；三个离群数据集（超长查询 arguana、超大规模 webis、非英文 vihealthqa）被 OOD 防护正确拦下并回退。距离分析显示命中/回退有清晰分界：命中簇最近邻距离 <1.1，回退簇距离 ≥3.3。

### 5.5 混合语料（Mega Corpus）泛化测试

把 10 个语料的文档拼接成 132 万文档的混合语料（doc_id 加前缀防冲突，35,558 条查询、247,199 条标注），模拟"任意新数据集"：

| 配置 | 说明 | NDCG@10 | MRR@10 | Recall@100 |
|---|---|--:|--:|--:|
| default | k1=1.2, b=0.75, k3=0, δ=0, rsj | **0.1247** | **0.0613** | **0.7335** |
| 词典（无 OOD 防护） | 误命中 webis → b=0.0 | 0.0012 | 0.0004 | 0.0160 |
| 词典（含 OOD 防护） | 判定分布外 → 回退启发式 | 0.0106 | 0.0054 | 0.1122 |

混合语料特征 cv_len=1.732 超出所有训练语料（最大 1.316），OOD 防护正确触发（vocab_size、query_idf_mean 越界），避免了把 webis 的 b=0.0 硬套上去的灾难性结果。

**结论 5（重要的普适性边界）：混合语料上默认参数反而优于自适应规则。** 混合语料的长度差异主要来自**域间**（不同子语料的长度尺度不同），而"cv_len 高 → b 小"的规律来自**域内**观察——把 b 压到 0.05 后长文档（长句子的法律/学术子语料）完全霸榜。这说明特征→参数规律是**域条件性**的，不是无条件普适的；真正的普适需要区分"长度异质性来自域内还是域间"（如长度分布多模态检测），或对混合语料按子语料分别应用参数。这一发现同时验证了 OOD 防护的必要性，也划出了当前规律的适用边界。

## 6. 局限性与未来工作

- **混合语料失效（最重要）**：§5.5 表明"cv_len 高 → b 小"在跨域混合语料上方向错误。未来工作：增加语料异质性特征（长度分布多模态、域间/域内方差分解）、混合语料按子语料分别预测，或用查询侧信息识别混合场景。
- **k3 与 k1 的交互**：启发式独立预测 k1/k3，但在 arguana 上两者组合过强（k3=7.45 + k1=0.53）；需要联合标定或让词典直接记住组合。
- **非英文语料**：vihealthqa（越南语）表明英文停用词密度等特征失真；需要语言无关特征或按语言分册的词典。
- **OOD 阈值的敏感性**：`oov_min_features=2, margin=0.5` 是在 9 个数据集 + 混合语料上调出的；更多数据集加入后需重新校验。
- **旧数据集 grid 上界的口径**：fiqa/trec-covid/webis 的 grid 上界在早期引擎版本上计算（查询词重复处理不同，对短查询影响小）；arguana/nfcorpus/scifact 已用修正引擎重跑。
- **上界估计的规模限制**：quora/scidocs/nq 未跑 grid（计算量），nq 评估为 500 条采样。
- **词典覆盖度**：目前 9 个条目，靠数据增强与后续新增数据集扩充；覆盖不足时回退启发式是主干，词典是增量记忆。
- **可扩展方向**：线性规则 → 小型回归/树模型；词典索引（KD-tree）支撑更大规模；按查询长度/语言自适应；TIRA/TREC 评测。

## 7. 快速开始（复现）

```bash
pip install -r requirements.txt

# 单数据集：预测参数（默认词典优先，未命中回退启发式）并保存 json
python main.py --dataset dataset/XXX --predict
python main.py --dataset dataset/XXX --predict --no-dict      # 只用启发式

# 单数据集：评估 default vs predicted
python main.py --dataset dataset/XXX --eval

# 构建参数词典（从 results/benchmark_results.json 的 grid 结果）
python main.py --build-dict --dict-threshold 2.0

# 批量实验 + 结果汇总（README 表格的复现入口）
python run_experiments.py --all --eval-queries -1
python summarize_results.py

# 专项实验
python experiment_k3.py                    # k3 消融（扫描 + 可选联合 grid）
python evaluate_dictionary.py --thresholds 2.0   # 词典留一法评估
python mega_corpus.py --eval-queries 500   # 混合语料泛化测试
```

数据格式支持项目标准格式（`docs.jsonl`/`queries.jsonl`/`qrels.jsonl`）与 BEIR 格式（`corpus.jsonl`/`queries.jsonl`/`qrels/*.tsv`，自动识别 `_id`/`qid` 与 `query-id/corpus-id` 表头）。中间结果全部存 `results/`（gitignored）。

### 性能说明

引擎使用倒排索引 + numpy 向量化打分；grid search 采用"查询计划"预计算（每条查询的倒排条目只拼接一次，每个参数组合一次向量化累加）。单机可跑 268 万文档（nq）；完整 grid 建议用 `--limit-queries` 采样查询数。
